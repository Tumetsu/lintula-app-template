# Changelog

Generated projects update between these releases with `copier update`. Each
release is a git tag of the same name.

## Unreleased

- The Docker image runs with `ENVIRONMENT=production` by default (JSON logs,
  API docs off, HSTS on). Override it with `-e ENVIRONMENT=development`.
- `make db-up`, `db-down` and `docker-up` fall back to the standalone
  `docker-compose` binary when the `docker compose` plugin is missing.
  `db-up` now waits until Postgres is healthy.
- Generated projects ship no migrations. Create the first one from your own
  models with `make migrate-new msg="initial schema"`. Template CI checks that
  this autogenerated migration applies and passes lint.
- `.env.example` is generated again (a `.gitignore` rule had kept it out of git).
- Frontend on TypeScript 7, linted with oxlint (type-aware, via tsgolint)
  instead of ESLint + typescript-eslint, which does not support TypeScript 7.
  The test-timeout `no-restricted-syntax` rule is gone; oxlint has no
  equivalent. dependency-cruiser parses with swc.

## v0.1.0

First release, extracted from crossbill.

- FastAPI + async SQLAlchemy + Alembic + PostgreSQL backend in DDD/hexagonal
  layout, with import-linter contracts and an example `notes` module.
- Vite + React + TanStack Router/Query frontend, MUI or Tailwind + shadcn/ui.
- OpenAPI export and orval client generation, checked for staleness in CI.
- ruff, pyright, ESLint, Prettier, knip, dependency-cruiser, jscpd, husky.
- Multi-stage Docker image serving API and frontend; docker compose with Postgres.
- GitHub Actions CI and a weekly template-update workflow.
- Claude Code CLAUDE.md, hooks and skills.
